### **Python 控制流详解：控制流决定代码的"执行路线"——用 `if/elif/else` 做条件分支，用 `for` 与 `while` 做循环重复，再用 `break`、`continue` 精确控制循环节奏，是让程序"会思考、会重复"的核心能力**

前面几节里，代码都是"从上往下一行行执行"的。但真实的 AI 应用需要程序**根据情况做不同的事**（比如 API 调用成功就解析、失败就重试），也需要**重复处理大量数据**（比如逐条处理文档、批量调用模型）。这就是控制流要解决的问题。本节把条件判断、循环、以及循环控制语句逐一讲透，并穿插 AI 开发中的典型用法。

### **一、条件判断：if / elif / else**

条件语句让程序根据某个表达式的真假，选择执行不同的代码块。它的基本形态是"如果……就……，否则……"。

最简单的单分支：

```python
score = 85
if score >= 60:
    print("及格了")
```

`if` 后面跟的是一个**条件表达式**（结果为 `True` 或 `False`，正是上一节讲的比较与逻辑运算），以冒号 `:` 结尾，下面**缩进**的代码块只在条件为真时执行。

加上 `else` 处理"否则"的情况：

```python
score = 45
if score >= 60:
    print("及格")
else:
    print("不及格")
```

多个条件时用 `elif`（else if 的缩写），可以有任意多个，Python 会**从上往下依次判断，命中一个就执行并跳出整个结构**：

```python
score = 85
if score >= 90:
    grade = "优秀"
elif score >= 80:
    grade = "良好"
elif score >= 60:
    grade = "及格"
else:
    grade = "不及格"
print(grade)   # 良好
```

这里有一个关键点：**顺序很重要**。因为命中第一个满足的分支就停止，所以条件要按合理的顺序排列。如果把 `score >= 60` 放在最前面，那么 85 分也会先命中它而被误判为"及格"。

#### **缩进：Python 的"语法灵魂"**

与其他很多语言用大括号 `{}` 不同，**Python 用缩进（通常是 4 个空格）来表示代码块的归属**。缩进错误会直接导致报错或逻辑错误，这是初学者最常见的坑：

```python
if True:
    print("这行属于 if")     # 缩进 4 格，属于 if 内部
print("这行总会执行")         # 没缩进，在 if 外部
```

务必保持缩进统一（推荐全程用 4 个空格，不要混用 Tab 和空格）。

#### **三元表达式：一行写完的简单判断**

当分支逻辑很简单时，可以用**条件表达式（三元运算符）**一行搞定：

```python
age = 20
status = "成年" if age >= 18 else "未成年"
print(status)   # 成年
```

它的结构是 `值A if 条件 else 值B`，非常适合给变量赋值时的简单二选一，让代码更简洁。

#### **match 语句：多值匹配（了解）**

Python 3.10 起新增了 `match / case`，适合对同一个变量做多种取值匹配，类似其他语言的 switch。初学可先了解：

```python
command = "start"
match command:
    case "start":
        print("启动")
    case "stop":
        print("停止")
    case _:              # _ 表示默认（其余情况）
        print("未知命令")
```

### **二、for 循环：遍历序列**

`for` 循环用于**遍历一个可迭代对象**（列表、字符串、字典、集合、range 等），对其中每个元素执行一次循环体。这是 Python 中最常用的循环形式。

```python
for name in ["小明", "小红", "小刚"]:
    print(f"你好，{name}")
```

#### **range()：生成数字序列**

当你需要"循环固定次数"或"生成一串数字"时，用 `range()`：

- `range(5)` → 0,1,2,3,4（从 0 开始，不含 5）
- `range(1, 6)` → 1,2,3,4,5（指定起止）
- `range(0, 10, 2)` → 0,2,4,6,8（指定步长）

```python
for i in range(3):
    print(f"第 {i + 1} 次尝试")
```

#### **遍历字典**

字典的遍历在 AI 开发中很常见（比如遍历 API 返回的参数）：

```python
config = {"model": "demo", "temperature": 0.7}
for key, value in config.items():   # 同时拿到键和值
    print(f"{key} = {value}")
```

默认 `for k in config:` 遍历的是**键**；用 `.items()` 同时取键值，用 `.values()` 只取值。

#### **enumerate 与 zip：两个高频实用工具**

- **`enumerate()`**：遍历时同时获得**索引和元素**，避免手动维护计数器：

```python
for index, name in enumerate(["A", "B", "C"]):
    print(index, name)   # 0 A / 1 B / 2 C
```

- **`zip()`**：**并行遍历多个序列**，把它们"配对"起来：

```python
names = ["小明", "小红"]
scores = [90, 85]
for name, score in zip(names, scores):
    print(f"{name}: {score}")
```

### **三、while 循环：条件满足时重复**

`while` 循环在**条件为真时反复执行**，直到条件变为假。它适合"不知道要循环几次、只知道停止条件"的场景，比如重试、等待、读取直到结束。

```python
count = 0
while count < 3:
    print(f"计数：{count}")
    count += 1          # 关键：必须让条件有机会变为假
```

**最大的陷阱是死循环**：如果循环体内没有任何语句能让条件最终变为 `False`，程序就会永远运行下去。上面例子中的 `count += 1` 就是防止死循环的关键——务必确保循环变量在变化。

一个贴近 AI 开发的例子——带重试次数的 API 调用逻辑：

```python
max_retries = 3
attempt = 0
success = False
while attempt < max_retries and not success:
    attempt += 1
    print(f"第 {attempt} 次请求...")
    # 假设这里调用 API，成功则 success = True
    success = True      # 模拟成功
print("完成" if success else "重试耗尽，失败")
```

#### **for 还是 while？**

一个简单的判断标准：**已知要遍历的对象或明确的次数，用 `for`；只知道"满足某条件才继续"、次数不定，用 `while`。** 实际开发中 `for` 用得更多。

### **四、循环控制：break、continue 与 else**

这三个关键字让你能更精细地控制循环的执行节奏。

#### **break：立即跳出整个循环**

一旦执行 `break`，循环立即结束，不再继续剩余的迭代。常用于"找到目标就停止"：

```python
for num in [3, 7, 2, 9, 4]:
    if num > 8:
        print(f"找到大于 8 的数：{num}")
        break            # 找到就停，不再往后找
```

#### **continue：跳过本次，进入下一次**

`continue` 不结束整个循环，而是**跳过当前这一轮剩下的代码**，直接开始下一次迭代。常用于"过滤掉不需要处理的项"：

```python
for num in range(1, 6):
    if num % 2 == 0:
        continue         # 跳过偶数
    print(num)           # 只打印 1 3 5
```

#### **循环中的 else（Python 特有）**

`for` 和 `while` 都可以带一个 `else` 子句，它在**循环正常结束（没有被 break 中断）时执行**。这个特性在"查找"场景中很优雅：

```python
target = 10
for num in [3, 7, 2, 9]:
    if num == target:
        print("找到了")
        break
else:
    print("整个列表里都没找到")   # 循环没被 break，才执行这里
```

理解要点：只要循环是被 `break` 打断的，`else` 就**不会**执行；只有循环自然跑完，`else` 才执行。

### **五、嵌套与实战组合**

真实代码里，条件和循环常常嵌套使用。下面这个例子综合了 `for`、`if/elif/else`、`continue`，模拟批量处理一批分数数据：

```python
scores = [92, 45, 78, -1, 88]
valid_count = 0
total = 0

for i, score in enumerate(scores):
    if score < 0:                     # 无效数据，跳过
        print(f"第 {i} 条数据无效，已跳过")
        continue
    valid_count += 1
    total += score
    if score >= 90:
        print(f"第 {i} 条：{score} 优秀")
    elif score >= 60:
        print(f"第 {i} 条：{score} 及格")
    else:
        print(f"第 {i} 条：{score} 不及格")

if valid_count > 0:
    print(f"有效数据 {valid_count} 条，平均分 {total / valid_count:.1f}")
```

这段代码把本节几乎所有知识点都用上了：`enumerate` 取索引、`continue` 过滤无效数据、`if/elif/else` 分级判断、循环结束后再做汇总统计。读懂并能独立写出它，就说明控制流你已经基本掌握了。

### **小结与练习建议**

本节的核心记忆点有三个：**`if/elif/else` 是自上而下、命中即止的分支结构，条件顺序很重要**；**`for` 用于遍历已知序列、`while` 用于条件不定的重复，且 `while` 一定要防死循环**；以及 **`break` 跳出、`continue` 跳过本次**，两者作用范围截然不同。

建议动手做一个综合练习来巩固：**写一个"猜数字"小游戏——程序内定一个目标数字，用 `while` 循环反复接收用户输入（用 `input()`），猜大了提示"大了"、猜小了提示"小了"，猜中就 `break` 并祝贺，同时用计数器记录一共猜了几次。** 这个练习能一次性用到 `while`、`if/elif/else`、`break` 和类型转换，非常适合检验本节的掌握程度。

掌握了控制流之后，你就能写出有逻辑、能重复的完整程序了，接下来可以顺利进入"字符串处理"或"推导式"的学习。如果你希望，我可以针对 `for` 循环的各种实用技巧（enumerate、zip、嵌套遍历）或 `while` 的实战场景再展开更多案例。
