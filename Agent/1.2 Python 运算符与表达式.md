### **Python 运算符与表达式详解：运算符是操作数据的"动词"，表达式则是能计算出一个值的完整语句——掌握算术、比较、逻辑、赋值、成员与身份六大类运算符，是写出正确判断与数据处理逻辑的关键**

如果说变量和数据类型是"名词"，那么运算符就是作用在它们身上的"动词"。而由变量、值和运算符组合成、最终能求出一个结果的整体，就叫**表达式**（如 `a + b`、`age >= 18`）。这一节我们把 Python 各类运算符逐一讲透，并特别说明在 AI 应用开发中最常踩坑和最常用到的地方。

### **一、先理清：表达式 vs 语句**

在深入运算符之前，先厘清一个基础但重要的概念区别：

- **表达式（Expression）**：能**计算出一个值**的代码，如 `3 + 5`、`x > 0`、`name.upper()`。表达式可以嵌入到其他地方使用。
- **语句（Statement）**：执行某个**动作**的完整指令，如 `x = 10`（赋值语句）、`if ...:`（条件语句）。

简单判断方法：能放在 `=` 右边、能被 `print()` 打印出结果的，通常就是表达式。运算符正是构建表达式的核心工具。

### **二、算术运算符**

用于数学计算，是最直观的一类：

| 运算符 | 含义 | 示例 | 结果 |
|--------|------|------|------|
| `+` | 加 | `7 + 3` | `10` |
| `-` | 减 | `7 - 3` | `4` |
| `*` | 乘 | `7 * 3` | `21` |
| `/` | 除（总返回 float） | `7 / 2` | `3.5` |
| `//` | 整除（向下取整） | `7 // 2` | `3` |
| `%` | 取余（模） | `7 % 3` | `1` |
| `**` | 幂 | `2 ** 10` | `1024` |

有几个特别值得注意的点：

- **`/` 总是返回浮点数**，即使能整除，`10 / 2` 也是 `5.0`。需要整数结果时用 `//`。
- **`//` 是向下取整**，对负数要小心：`-7 // 2` 得到的是 `-4`（往更小的方向取），而不是 `-3`。
- **`%` 取余在实战中极常用**，比如判断奇偶（`n % 2 == 0` 为偶数）、每隔 N 个执行一次（`i % 10 == 0`），在批量处理数据时经常用到。

算术运算符也能用于部分非数字类型：

```python
print("Ha" * 3)          # HaHaHa   字符串重复
print([0] * 4)           # [0, 0, 0, 0]  列表重复
print("你好" + "世界")    # 你好世界  字符串拼接
```

### **三、比较运算符**

比较两个值，**结果永远是布尔值（True / False）**，是条件判断的基础：

| 运算符 | 含义 | 示例 | 结果 |
|--------|------|------|------|
| `==` | 相等 | `3 == 3` | `True` |
| `!=` | 不相等 | `3 != 5` | `True` |
| `>` | 大于 | `5 > 3` | `True` |
| `<` | 小于 | `5 < 3` | `False` |
| `>=` | 大于等于 | `3 >= 3` | `True` |
| `<=` | 小于等于 | `2 <= 3` | `True` |

初学者最常犯的错误是**混淆 `=` 和 `==`**：`=` 是赋值（把右边给左边），`==` 才是比较是否相等。在 `if` 里误写成 `=` 会直接报语法错误。

Python 还支持一个很优雅的特性——**链式比较**，可以像数学一样连写：

```python
age = 25
print(18 <= age < 60)    # True，等价于 18 <= age and age < 60
```

另外要注意 `==` 比较的是**值**是否相等，而不是是否为同一个对象（后者用 `is`，见第七节）。

### **四、逻辑运算符**

用于组合多个布尔条件，是构建复杂判断的核心：

| 运算符 | 含义 | 说明 |
|--------|------|------|
| `and` | 与 | 两边都为真才为真 |
| `or` | 或 | 有一边为真即为真 |
| `not` | 非 | 取反 |

```python
age = 20
has_ticket = True
if age >= 18 and has_ticket:
    print("可以入场")
```

这里有两个进阶但非常实用的机制：

- **短路求值（Short-circuit）**：`and` 遇到第一个假值就停止，`or` 遇到第一个真值就停止。这不仅提升效率，还能防止报错。例如 `data and data.get("key")`——如果 `data` 为空就直接返回，不会去执行右边导致崩溃，这在解析 API 返回时很常见。
- **返回的不一定是布尔值**：`and` / `or` 实际返回的是"决定结果的那个操作数"本身。比如 `"" or "默认值"` 返回 `"默认值"`，常被用来设置默认值：`name = user_input or "匿名用户"`。

### **五、赋值运算符**

除了基本的 `=`，还有一系列"复合赋值"运算符，是"先运算再赋值"的简写：

| 运算符 | 等价于 | 示例 |
|--------|--------|------|
| `+=` | `x = x + ...` | `count += 1` |
| `-=` | `x = x - ...` | `total -= 5` |
| `*=` | `x = x * ...` | `n *= 2` |
| `/=` | `x = x / ...` | `v /= 3` |
| `//=`、`%=`、`**=` | 对应整除/取余/幂 | `x **= 2` |

```python
total = 0
for price in [10, 25, 30]:
    total += price      # 累加，等价于 total = total + price
print(total)            # 65
```

`+=` 也能用于列表和字符串：`items += [新元素]`、`text += "追加内容"`。在循环中累加计数、拼接结果时几乎无处不在。

Python 3.8 起还引入了**海象运算符 `:=`**（赋值表达式），可以在表达式内部同时赋值和使用，属于进阶特性，初学可先了解：

```python
if (n := len([1, 2, 3])) > 2:
    print(f"长度是 {n}")   # 在判断的同时把长度存进 n
```

### **六、成员运算符：`in` 与 `not in`**

判断某个元素是否存在于容器（字符串、列表、字典、集合等）中，返回布尔值。这在实际开发中使用频率极高：

```python
print("py" in "python")            # True，子串判断
print(3 in [1, 2, 3])              # True，列表成员
print("name" in {"name": "小明"})  # True，注意字典判断的是「键」
print("z" not in "python")         # True
```

特别提醒：对**字典**用 `in` 时，判断的是**键（key）**而非值。想判断值需用 `value in d.values()`。同时，`in` 对**集合**的判断速度远快于列表，处理大量数据的去重与查找时应优先考虑集合。

### **七、身份运算符：`is` 与 `is not`**

`is` 判断两个变量是否指向**同一个对象**（内存地址相同），而 `==` 判断**值**是否相等。这是初学者极易混淆的地方：

```python
a = [1, 2, 3]
b = [1, 2, 3]
print(a == b)   # True，值相同
print(a is b)   # False，是两个不同的对象
```

**核心使用规则**：判断是否为 `None`、`True`、`False` 时，**必须用 `is`**（如 `if result is None:`），因为这些是全局唯一的单例对象；而比较普通的值（数字、字符串是否相等）则用 `==`。

### **八、运算符优先级：谁先算？**

当一个表达式包含多种运算符时，Python 按固定的优先级顺序计算。从高到低大致为：

1. `**`（幂）
2. `*`、`/`、`//`、`%`（乘除类）
3. `+`、`-`（加减）
4. 比较运算符（`==`、`<`、`in`、`is` 等）
5. `not`
6. `and`
7. `or`

```python
print(2 + 3 * 4)        # 14，先乘后加
print((2 + 3) * 4)      # 20，括号改变顺序
print(True or False and False)   # True，and 优先级高于 or
```

一条黄金实践建议：**不确定优先级时，直接加括号。** 括号不仅保证结果正确，也让代码可读性大幅提升，即使多余也无妨。最后一个例子如果写成 `(True or False) and False` 结果就变成 `False` 了——用括号明确表达意图，远比背诵优先级表可靠。

### **小结与练习建议**

本节的核心记忆点有三个：**比较与逻辑运算的结果是布尔值，是所有条件判断的基础**；**`=` 是赋值、`==` 是比较值、`is` 是比较对象身份**，三者切不可混淆；以及 **`in` 和短路求值在处理 API 数据时极为实用**。

建议动手做一个综合练习来巩固：**写一段代码，判断一个整数是否为"能被 3 整除但不能被 5 整除，且大于 10"的数**——这一个题目就能同时用到算术（`%`）、比较（`>`）和逻辑（`and`、`not`）运算符，还能顺带练习优先级与括号的运用。
