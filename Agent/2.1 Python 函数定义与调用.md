### **Python 函数定义与调用详解：函数是把一段可复用逻辑"打包命名"的基本单元——用 `def` 定义、用"函数名()"调用，通过参数接收输入、用 `return` 返回结果，是组织代码、消除重复、构建 AI 应用模块化结构的第一步**

从这一节开始，我们进入第二个大模块——函数。如果说前面学的语法、循环、判断是"零件"，那么函数就是把这些零件**组装成一个个可复用的"工具"**。在 AI 应用开发中，"调用模型""清洗一段文本""解析一条返回"这些动作都会被封装成函数，用一次定义、多次调用。掌握函数的定义与调用，是从"写脚本"迈向"写程序"的关键一步。本节聚焦最核心的两件事：**如何定义一个函数，以及如何正确地调用它并拿到结果。**

### **一、为什么需要函数**

先理解动机。假设你要在程序里多次向用户问好，如果不用函数，代码会到处重复：

```python
print("你好，小明，欢迎使用本系统")
print("你好，小红，欢迎使用本系统")
print("你好，小刚，欢迎使用本系统")
```

一旦要修改问候语，就得改很多处。用函数则可以"定义一次，到处调用"：

```python
def greet(name):
    print(f"你好，{name}，欢迎使用本系统")

greet("小明")
greet("小红")
greet("小刚")
```

函数带来的核心价值有三个：**复用**（同样的逻辑不用重写）、**可维护**（改一处即可全局生效）、**可读**（一个好名字胜过一堆注释，`greet()` 一看就懂）。这也是软件开发中著名的 **DRY 原则（Don't Repeat Yourself，不要重复自己）** 的直接体现。

### **二、函数的定义：def 语句**

在 Python 中，用关键字 `def` 来定义函数，它的基本结构如下：

```python
def 函数名(参数列表):
    """文档字符串（可选，用于说明功能）"""
    函数体              # 缩进的代码块
    return 返回值        # 可选
```

逐部分拆解这个结构：

- **`def`**：定义函数的关键字，固定写法。
- **函数名**：遵循变量命名规则，推荐用小写加下划线的 `snake_case`，且应是**动词或动宾短语**（如 `calculate_total`、`send_request`），让人一看就知道它"做什么"。
- **括号与参数**：括号里放参数（函数需要的输入），即使没有参数，括号也**不能省略**。
- **冒号 `:`**：定义行以冒号结尾。
- **函数体**：**必须缩进**（通常 4 个空格），这是属于函数的代码。
- **文档字符串（docstring）**：紧跟定义行的字符串，用来说明函数用途，是良好习惯。

一个带文档字符串的完整定义：

```python
def calculate_area(width, height):
    """计算矩形面积"""
    area = width * height
    return area
```

需要特别强调：**定义函数时，函数体内的代码并不会立即执行。** 定义只是"告诉 Python 有这么一个工具"，就像写好了菜谱但还没开火做菜。只有当你**调用**它时，代码才真正运行。

### **三、函数的调用**

调用一个函数，就是写出**函数名后面跟一对括号**，并在括号里传入需要的参数：

```python
def calculate_area(width, height):
    return width * height

result = calculate_area(5, 3)   # 调用，传入 5 和 3
print(result)                   # 15
```

调用的完整过程是这样的：程序执行到 `calculate_area(5, 3)` 时，会**跳转到函数定义处**，把 `5` 交给 `width`、`3` 交给 `height`，执行函数体，遇到 `return` 就带着结果**跳回调用的地方**，并把返回值"替换"到调用位置。所以 `result` 最终得到的就是 `15`。

一个常见的初学者困惑是**定义顺序**：在 Python 中，**函数必须先定义、后调用**。如果在定义之前就调用，会报 `NameError`：

```python
greet("小明")           # 报错！此时 greet 还没被定义
def greet(name):
    print(f"你好，{name}")
```

正确做法是把定义写在调用之前。

### **四、参数与返回值：函数的"输入"和"输出"**

函数可以看成一个"加工机器"：**参数是原料（输入），return 是成品（输出）**。理解这两者的配合是本节的重点。

#### **1. 形参与实参**

这是两个需要区分的术语：

- **形参（形式参数，parameter）**：定义函数时括号里的变量名，是"占位符"，如 `def greet(name)` 中的 `name`。
- **实参（实际参数，argument）**：调用函数时真正传进去的值，如 `greet("小明")` 中的 `"小明"`。

调用时，实参会按顺序"赋值"给对应的形参。

#### **2. 返回值：return 的作用**

`return` 语句有两个作用：**把结果送出函数**，同时**立即结束函数的执行**（`return` 后面的代码不再运行）：

```python
def check_age(age):
    if age < 0:
        return "年龄无效"     # 一旦返回，函数就结束
    return "年龄有效"         # 上面没返回才会走到这里

print(check_age(-5))          # 年龄无效
```

这个"提前返回"的特性很实用，常用于**先处理异常/边界情况，再处理正常逻辑**（称为"卫语句"），能让代码更扁平、更清晰。

#### **3. 没有 return 会怎样**

如果一个函数没有 `return` 语句，或者只写了一个光秃秃的 `return`，那么它默认返回 **`None`**：

```python
def say_hello(name):
    print(f"你好，{name}")     # 只打印，没有 return

result = say_hello("小明")     # 打印了"你好，小明"
print(result)                  # None
```

这里要厘清一个初学者极易混淆的概念：**`print` 和 `return` 完全不同**。`print` 只是把内容显示到屏幕上给"人"看，`return` 才是把值交给"程序"继续使用。一个只 `print` 不 `return` 的函数，它的结果**无法被后续代码接住和运算**。在 AI 开发中，处理数据的函数几乎都应该用 `return` 返回结果，而不是只打印。

#### **4. 返回多个值**

Python 的函数可以"返回多个值"，本质上是打包成一个元组，配合解包使用非常方便：

```python
def get_min_max(numbers):
    return min(numbers), max(numbers)   # 返回两个值

low, high = get_min_max([3, 1, 9, 4])   # 解包接收
print(low, high)                        # 1 9
```

这在需要函数同时返回"多项结果"时很常用，比如同时返回"是否成功"和"具体数据"。

### **五、无参数与无返回值的函数**

不是所有函数都需要参数或返回值。根据"有无输入、有无输出"，函数大致有四种组合，下面用一张表配合示例说明：

| 类型 | 特点 | 典型场景 |
|------|------|----------|
| 无参无返回 | 只执行固定动作 | 打印固定的欢迎语、分隔线 |
| 有参无返回 | 根据输入执行动作 | 按名字打印问候、写日志 |
| 无参有返回 | 生成/获取某个值 | 获取当前时间、生成随机 ID |
| 有参有返回 | 输入加工成输出（最常用） | 计算、转换、调用 API 并返回结果 |

```python
def print_separator():          # 无参无返回
    print("-" * 30)

def get_greeting():             # 无参有返回
    return "欢迎使用 AI 助手"

print_separator()
print(get_greeting())
```

其中**"有参有返回"是 AI 开发中最主流的形态**，因为大多数函数都在做"接收数据 → 加工 → 返回结果"的事。

### **六、AI 开发实战：封装一个文本处理函数**

把本节知识综合起来，看一个贴近真实场景的例子——封装一个"构造并返回提示词"的函数，它衔接了你前面学过的字符串处理：

```python
def build_prompt(topic, style="正式"):
    """根据主题和风格构造一个提示词，返回字符串"""
    topic = topic.strip()                    # 清洗输入
    prompt = f"请以「{style}」的风格，写一段关于「{topic}」的介绍，100 字以内。"
    return prompt                            # 返回结果供后续使用

# 调用
p1 = build_prompt("  人工智能  ")
p2 = build_prompt("Python", "轻松幽默")
print(p1)
print(p2)
```

这个函数体现了良好的设计：它**有清晰的名字**（一看就知道是构造提示词）、**接收输入并返回结果**（而非只打印，方便后续把 `p1` 传给模型 API）、**用文档字符串说明用途**。这正是实际 AI 项目中封装函数的典型写法。

### **小结与练习建议**

本节的核心记忆点有三个：**用 `def` 定义、用"函数名()"调用，且必须先定义后调用**；**形参是定义时的占位符、实参是调用时传入的真实值**；以及最关键的——**`return` 是把结果交给程序继续使用，`print` 只是显示给人看，处理数据的函数应当用 `return` 返回结果，没有 `return` 则默认返回 `None`**。

建议动手做一个综合练习来巩固：**写一个函数 `summarize_text(text)`——它接收一段文本，先用 `strip` 清洗，然后返回一个包含"字符数"和"单词数"两个值的结果（提示：用 `len` 和 `split`），最后在函数外调用它并用解包接收这两个值、格式化打印出来。** 这个练习能一次性用到函数定义、参数、多返回值、解包，还能顺带复习字符串处理。
