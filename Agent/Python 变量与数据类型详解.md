### **Python 变量与数据类型详解：变量是"贴在数据上的标签"，数据类型则决定了数据能做什么——掌握数字、字符串、布尔与列表、字典、元组、集合六大核心类型是 AI 开发的第一块基石**

变量与数据类型是 Python 编程最底层、也最容易被"以为懂了其实没懂"的部分。理解它们不仅关乎语法，更关乎你后续处理 API 数据、组织模型输入输出时的思维方式。下面我们从"变量到底是什么"讲起，逐一拆解每种数据类型的特性、用法和常见陷阱。

### **一、变量：不是"盒子"，而是"标签"**

很多教程把变量比作"装东西的盒子"，但 Python 的真实机制更接近**给数据贴标签**。当你写 `x = 10` 时，内存里先创建了整数对象 `10`，然后变量名 `x` 像一张便利贴一样贴在它上面。

这个理解很关键，因为它解释了 Python 的赋值行为：

```python
x = 10
y = x        # y 也贴到同一个 10 上
x = 20       # x 撕下来重新贴到 20 上，y 不受影响
print(x, y)  # 20 10
```

几个要点：

- **变量无需声明类型**：Python 是"动态类型"语言，同一个变量可以先指向整数、再指向字符串（虽然不推荐这么滥用）。
- **命名规则**：只能由字母、数字、下划线组成，不能以数字开头，区分大小写。推荐用小写加下划线的 `snake_case`（如 `user_name`）。
- **命名要有意义**：`total_price` 远比 `tp` 或 `a` 更利于阅读和维护。
- **查看类型**：随时用 `type(变量)` 检查一个变量当前指向什么类型。

### **二、可变 vs 不可变：贯穿所有类型的核心分水岭**

在逐个介绍类型前，必须先建立一个至关重要的概念——**可变性（mutability）**。这是初学者最常踩的坑，也是理解列表、字典行为的钥匙。

- **不可变类型（immutable）**：数字、字符串、布尔、元组。一旦创建，其值不能被修改，任何"修改"其实都是创建了新对象。
- **可变类型（mutable）**：列表、字典、集合。可以在原对象上增删改。

这个区别会直接影响函数传参、数据共享时的行为，后面每种类型都会再次提到它。

### **三、数字类型（Numbers）**

Python 的数字主要有三种：

- **整数（int）**：没有大小限制（能算超大数），如 `100`、`-7`、`10000000000000000`。
- **浮点数（float）**：带小数点的数，如 `3.14`、`-0.5`、`2.0`。
- **复数（complex）**：如 `3 + 4j`，AI 应用开发中极少用到，了解即可。

常用操作与注意点：

```python
a = 10
b = 3
print(a + b)    # 13
print(a / b)    # 3.333...  除法结果总是 float
print(a // b)   # 3         整除（向下取整）
print(a % b)    # 1         取余
print(a ** b)   # 1000      幂运算
```

有两个常见陷阱值得特别提醒：

- **浮点数精度问题**：`0.1 + 0.2` 的结果并不精确等于 `0.3`，而是 `0.30000000000000004`。这是所有编程语言的通病（二进制无法精确表示某些小数），涉及金额等精确计算时应使用 `decimal` 模块。
- **除法总返回 float**：即使 `10 / 2` 结果也是 `5.0` 而非 `5`，需要整数时用 `//`。

### **四、字符串（str）**

字符串是 AI 开发中出现频率最高的类型——提示词（prompt）、模型返回、文档内容全是字符串。它是**不可变**的。

创建方式很灵活：

```python
s1 = '单引号'
s2 = "双引号"
s3 = """三引号可以
跨多行，常用于长提示词"""
```

必须掌握的核心操作：

- **f-string 格式化**（首选）：`f"你好，{name}，你有 {count} 条消息"`，还能做运算和格式控制，如 `f"{price:.2f}"` 保留两位小数。
- **索引与切片**：`s[0]` 取第一个字符，`s[-1]` 取最后一个，`s[1:4]` 取子串，`s[::-1]` 反转字符串。
- **常用方法**：`.strip()` 去除首尾空白、`.split(",")` 按分隔符切分成列表、`"-".join(列表)` 拼接、`.replace(旧, 新)`、`.upper()` / `.lower()`、`.startswith()` / `.endswith()`、`.find()`。

```python
text = "  Python, AI, Agent  "
items = text.strip().split(", ")
print(items)              # ['Python', 'AI', 'Agent']
print(" | ".join(items))  # Python | AI | Agent
```

因为字符串不可变，`.replace()`、`.upper()` 等方法都是**返回新字符串**，原字符串不变——记得用变量接住返回值。

### **五、布尔类型（bool）**

布尔只有 `True` 和 `False` 两个值，用于条件判断。它其实是整数的子类型（`True` 等于 `1`，`False` 等于 `0`，可以参与运算）。

一个非常实用的概念是**真值（Truthiness）**：在 `if` 判断中，很多非布尔值会被自动当作真或假：

- **被当作 False 的值**：`0`、`0.0`、`""`（空字符串）、`[]`（空列表）、`{}`（空字典）、`None`。
- **其余几乎都是 True**。

```python
name = ""
if name:
    print("有名字")
else:
    print("名字为空")   # 会执行这句，因为空字符串为假
```

这个特性让代码可以写得很简洁，比如用 `if items:` 判断列表是否非空，而不必写 `if len(items) > 0:`。

### **六、四大容器类型**

当需要组织多个数据时，就用到容器。下面用一张表快速对比它们的核心特征，再逐一说明：

| 类型 | 写法 | 有序 | 可变 | 元素可重复 | 典型用途 |
|------|------|------|------|------|------|
| 列表 list | `[1, 2, 3]` | 是 | 是 | 是 | 有序数据集合、批量处理 |
| 元组 tuple | `(1, 2, 3)` | 是 | 否 | 是 | 固定不变的数据、多值返回 |
| 字典 dict | `{"k": "v"}` | 是* | 是 | 键唯一 | 键值映射、JSON/API 数据 |
| 集合 set | `{1, 2, 3}` | 否 | 是 | 否（自动去重） | 去重、成员判断 |

（*字典从 Python 3.7 起保证保留插入顺序。）

#### **1. 列表（list）——最常用的有序集合**

列表是**可变、有序**的，可以随时增删改，元素类型可以混合。

```python
nums = [3, 1, 4, 1, 5]
nums.append(9)        # 末尾添加 → [3,1,4,1,5,9]
nums.insert(0, 0)     # 指定位置插入
nums.remove(1)        # 删除第一个值为 1 的元素
nums.sort()           # 原地排序
print(nums[0], nums[-1])   # 索引访问
print(nums[1:3])           # 切片
print(len(nums))           # 长度
```

因为列表可变，`.append()`、`.sort()` 这类方法是**原地修改**、返回 `None`，千万不要写 `nums = nums.sort()`（会把 `nums` 变成 `None`）。

#### **2. 字典（dict）——AI 开发中的重中之重**

字典存储**键值对（key-value）**，是 AI 应用里最重要的类型，因为几乎所有 API 的请求体和返回体都是字典/JSON 结构（如 `{"role": "user", "content": "你好"}`）。

```python
user = {"name": "小明", "age": 25, "skills": ["Python", "AI"]}
print(user["name"])            # 访问，键不存在会报错
print(user.get("email", "无")) # 更安全，键不存在返回默认值
user["age"] = 26              # 修改
user["city"] = "北京"          # 新增
for key, value in user.items():  # 遍历键值
    print(key, value)
```

强烈建议用 `.get(键, 默认值)` 来读取可能不存在的键，避免程序因 `KeyError` 崩溃——这在解析模型返回时尤其重要。

#### **3. 元组（tuple）——不可变的列表**

元组和列表很像，但**不可变**。因为不能修改，它适合表示"一组固定的数据"，也常用于函数返回多个值。

```python
point = (3, 5)
x, y = point          # 解包，x=3, y=5

def min_max(nums):
    return min(nums), max(nums)   # 实际返回一个元组

low, high = min_max([4, 1, 9, 2])
print(low, high)      # 1 9
```

#### **4. 集合（set）——自动去重与快速查找**

集合是**无序、不重复**的元素集合，最大用途是去重和高效的成员判断（`in` 操作比列表快得多）。

```python
tags = ["ai", "python", "ai", "agent", "python"]
unique = set(tags)          # {'ai', 'python', 'agent'} 自动去重
print("python" in unique)   # True，判断成员非常快
print(len(unique))          # 3
```

集合还支持交集 `&`、并集 `|`、差集 `-` 等运算，处理"两批数据的重叠"时很方便。

### **七、None：表示"什么都没有"**

`None` 是一个特殊值，表示"空"或"没有值"，常作为函数的默认返回、变量的初始占位。判断时**要用 `is` 而不是 `==`**：

```python
result = None
if result is None:
    print("还没有结果")
```

### **八、类型转换（Type Casting）**

不同类型之间经常需要转换，尤其是处理用户输入或 API 数据时（比如从接口拿到的数字可能是字符串形式）：

```python
int("123")      # 字符串转整数 → 123
str(456)        # 数字转字符串 → "456"
float("3.14")   # → 3.14
list("abc")     # → ['a', 'b', 'c']
bool(0)         # → False
```

注意转换可能失败：`int("abc")` 会抛出 `ValueError`，因此对不可信输入应配合异常处理。

### **小结与练习建议**

这一节的核心记忆点有三个：**变量是标签而非盒子**、**可变与不可变的区别**、以及**字典是 AI 开发中最关键的类型**。数字、字符串、布尔属于不可变的基础类型；列表、字典、集合是可变容器，元组则是不可变的"只读列表"。

为了真正掌握，建议动手做一个小练习：**写一段代码，把一句话按空格拆成单词列表，用集合去重，再用字典统计每个单词出现的次数，最后格式化打印结果。** 这一个练习就能同时用到字符串方法、列表、集合、字典和 f-string，是巩固本节内容最有效的方式。
